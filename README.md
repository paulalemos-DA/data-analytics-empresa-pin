# README

# 📊 Análisis de Datos — Empresa PIN

## Proyecto Integrador Final

Proyecto integral de análisis de datos desarrollado durante mi
formación en Data Analytics.

El proyecto aborda diferentes etapas del proceso de análisis:
creación y consulta de una base de datos en MySQL, análisis
exploratorio utilizando Python y Pandas, y desarrollo de un
dashboard interactivo en Power BI.

---

## 🎯 Objetivo

Desarrollar un proceso completo de análisis de datos utilizando
diferentes herramientas para transformar datos provenientes de
distintas fuentes en información útil para el análisis.

---

## 🛠️ Herramientas

- MySQL
- Python
- Pandas
- Power BI
- DAX
- CSV

# 🗄️ 1. SQL / MySQL

Se creó una base de datos denominada `Empresa` y se desarrollaron
las tablas correspondientes a:

- Empleados
- Sucursales
- Proveedores


Se realizaron consultas SQL para obtener información relacionada
con empleados, sucursales y proveedores.

[Ver consultas SQL](SQL/consultas.sql)

---

# 🐍 2. Python

Se utilizaron Python y Pandas para importar y analizar los datos
correspondientes a clientes, productos y transacciones.

Se realizó un análisis exploratorio de datos (EDA) y posteriormente
se trabajó en la migración de los DataFrames a MySQL.

En Python se crearon 3 tablas en la base de datos de SQL:
- Clientes
- Productos
- Transacciones

   Y se migraron los 3 dataframes a su respectiva tabla


[Ver análisis en Python](Python/analisis_exploratorio.ipynb)

---

# 📊 3. Power BI

Se conectaron las seis tablas de la base de datos con Power BI.

Durante esta etapa se trabajó en:

- Normalización de datos
- Modelo relacional
- Relaciones entre tablas
- Columna Total_Transaccion
- Medidas DAX
- KPIs
- Segmentadores
- Visualizaciones

---

# 📈 Dashboard

## Resumen ejecutivo

![Dashboard general](Dashboard/dashboard-general.png)

El dashboard permite analizar indicadores relacionados con
facturación, transacciones, unidades vendidas, productos,
empleados y clientes.

También permite analizar la evolución mensual de la facturación,
la facturación por categoría y el desempeño de las sucursales.

---

## 🔎 Principales análisis

El dashboard permite filtrar la información mediante:

- Año
- Trimestre
- Sucursal
- Categoría
- Forma de pago
- Cliente
